# 统一比较与单一路线选择

2026-10-26；基于固定官方源码和公开Schema，不使用宣传数据量作为质量评分。

| 决策维度 | A 原生TM | B ScenarioRunner | C Bench2Drive |
|---|---|---|---|
| 车辆+行人来源 | 原生spawn/navigation，现有API | XML+行为树，场景干预较多 | 已采集，文件尚未取得 |
| 20–40m与六摄方向 | 有机会、无保证；需统计有效像素 | 前车25m有设计机会，其余触发距离不等同可见距离 | 公开场景丰富，单包未审查，远场JPEG20支持未知 |
| Actor/Box来源 | 运行时可完整记录自身及背景动态对象 | 可从provider/world获取，替换ID需追踪 | Schema有ID/Box，静态近邻关联与坐标字段有风险 |
| 背景/Unknown | 独立语义/实例/环境库存；完整Mesh缺失 | 同左，默认criteria不解决 | 已有语义/实例/部分静态标注最丰富，但非完整物理GT |
| 时间证据 | 可直接保留真实snapshot及image时间 | 默认传感器收齐tag不代表同frame，需补核验 | save计数命名，原frame/timestamp缺失；不能补造 |
| 自然状态 | physics轨迹可观察，仍非接触认证 | 隐藏/teleport/恒速/关physics增加负担 | 现成帧缺生成过程/轮胎接触，需序列证据 |
| 新独立Final | 0，历史足迹覆盖不完整 | 0，标准路线重复 | 0，训练集/旧观察资料不自动独立 |
| 最少放置器代码 | 少量固定编排 | 外部成熟但内部放置复杂 | **最少** |
| 本机部署成本 | **最低新增依赖** | 最高 | 离线低，但许可/下载待解决 |
| 决定 | **唯一优先提案** | 保留审查资料，不主动部署 | **唯一条件备用** |

选择A是当前单人开发、现有服务器环境和时间身份审计的权衡；不是声称A的自然场景成功率已优于B/C。A最重要的剩余风险是：不搜索位置的单次小流量运行可能没有同时可评车辆/行人和20–40m支持。应把这种结果记录为支持不足并结束，不能用扩大随机生成弥补失败。

C省去所有目标生成，最适合作为将来对照，但当前证据不足以标Ready：许可证范围差异、HF服务器访问失败、原始时间缺失、static boxes近邻绑定。B虽有可控互动，不解决这些共同几何/身份风险，还增加旧依赖和隐藏Actor生命周期；不作为自动回退。

统一判定：来源存在≠本次TrafficGenerated；生成≠ActorIdentityAvailable；身份≠GeometryEvaluable；可评价Box≠NaturalSceneQualified；上述均不推出训练或视觉安全通过。三条路线均无完整物理Mesh/全背景真值。`NoSourceReady`只描述本轮尚未验证的数据资格；已有足够证据提出A的限定Pilot，不需要继续扩大资料搜索。
