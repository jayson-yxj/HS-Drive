# M6-B — Oracle Low-Speed Maneuvers & Runtime Tail Analysis

**总体 Partial。候选不替换默认控制器，不开启倒车泊车或视觉控制。** 基线 `7ec866f`；独立分支 `feat/m6b-oracle-maneuvers`。全部驾驶结果为 **Privileged CARLA 0.9.15 / Town03 / Tesla Model3 / Epic / 0.05s**，无视觉推理或GPU训练并发。精确源码、配置、车型Physics和运行日志SHA随每次试验保存。

## 1. 停车几何及配对结果

历史9m短路线实际距导航终点 **1.428m**：固定1m内部保留量，加内部停止点前 **0.428m**残余。另一历史试验残余更大。因此不能直接删除1m并声称解决控制问题。旧Planner还有近目标0.5m coast envelope，旧Controller有提前HOLD与低速effort残留路径；这些分别审查并保留原实现。

新增 `StopGoal` 明确Actor原点的XY/yaw、坐标、时间、来源、0.5m位置/5°航向/0.08m/s终速/连续1s保持。停止位姿独立检查车身道路合法；B通过末端切向辅助点适配旧Planner内部1m保留量，不修改障碍3m间距。C增加显式低速状态机，记录每次转换；紧急制动仍立即独立触发。

24组正式配对：两位置×两长度/速度组合(9m/1m/s、25m/2.5m/s)×两重复×A/B/C。同配对路线和Physics SHA一致。A/B/C共用新墙钟仪器，不能视作旧调度器完全复现。

| 实验臂 | 停车位置/航向/保持/道路通过 | 舒适性联合门禁 |
|---|---:|---:|
| A 旧Planner+Controller | 0/8 | 0/8 |
| B 仅明确停止目标/当前距离 | 4/8 | 0/8 |
| C B+低速状态机 | 6/8 | 0/8 |

C在历史位置9m误差约0.052/0.060m，独立位置9m却**越过目标**0.689/0.716m。报告保留带符号与绝对距离。C的最大原始减速度16.60m/s²、最大原始Jerk338.16m/s³；这是全运动/降级混合轨迹的最坏值，不能全归因于普通制动。单列raw、250ms、启动段、正常/降级命令窗口和尖峰上下文，保留真实物理突变。

普通直道/弯道/路口两重复共六次：都达到路线末端，但均未通过新增停车门禁，终点误差约0.69–1.16m；无记录lane invasion。旧有限polyline最近距离会把末端纵向超调计入CTE，另报切向横向误差，不能把这一数值解释成横向偏离1m。

**结论：目标语义修正有效；低速候选的可重复性和舒适性不足。** 不以6/8成功升级默认，更不能称为自动泊车。

## 2. 动力学证据

复用M4.7/M4.8物理证据，新做6组恒定油门/缓升/滑行/保持探针，原Physics SHA均为 `3c4932cd550d47893d9051e335bf798424dfd07138ebf150a98820a57af047e6`。

恒定0.10油门与四秒内缓升到约0.10均未有效起步；恒定0.15出现延迟起步、gear0→1附近Jerk约284.19m/s³，两重复一致。原始速度导数和CARLA加速度吻合，不能仅视为数值滤波口径问题。油门命令变化率小并不保证真实动力学平滑；gear/接触/传动内部机制尚未因果分离。

单位置可滑行到静止，不表示跨道路可精确停车。候选coast模型在有坡度道路失配，某些强减速由无效轨迹/计划过期后的保护触发；紧急动作不因舒适性而削弱。上述有限实验不能证明全部可能控制策略不可行，也不授权修改原Physics。

## 3. 静态绕行与拒绝

只在同向相邻Driving车道、Broken标线、允许去/回变道的两处道路执行，候选有完整旋转障碍盒、车身膨胀、曲率约束、道路网格审计及原六秒在线Safety。四次合法绕行均回原路线并通过终点要求，四次障碍清除后均恢复到终点。Broken事件完整保留；不当作实线穿越。

双车道阻塞时几何正确返回 `NoFeasibleBypass`。**道路126没有碰撞却侵入原3m停车余量，触发当前碰撞保护，不能算安全拒绝通过。** 不将“没撞”替代停车间距验收。第一次两处拒绝场景因新spawn Actor未进入快照而退出，原失败记录保留，修复初始化tick后用独立名字补测，没有调控制参数。

Actor Box平面包络不等于渲染Mesh；离线记录车身审计包含实际OBB偏置、roll/pitch及安全余量，但仍是采样与OpenDRIVE参考，路缘Mesh接触保持Unknown。没有动态通用绕行、路口变道或交通规则完整验证。
