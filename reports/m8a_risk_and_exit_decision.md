# M8-A 风险与退出决策

**当前退出类型为 AssetNoGo。其含义是证据链未越过资产门禁；没有足够证据评价 PETR 本身。**

本轮按照用户要求在资产失败后停止。固定源码 `f7525f93467a33707ef401c587a52d5e7b34de74`，配置 `petr_r50dcn_gridmask_c5.py`；实际执行协议见[冻结记录](m8a_execution_logs/official_attempt_01/freeze.json)。资产与总P0预算分别不超过1/5人日，属于上限，不能解释为必须耗尽预算或无界重试。实际网络请求约18.14s。

| 风险/不确定性 | 本轮证据 | 决策 |
|---|---|---|
| 官方权重未取到 | Google连接超时；百度目录errno=-7；checkpoint路径/大小/SHA均无 | AssetNoGo；不安装后续环境 |
| 百度错误归因不足 | 提取码验证成功，目录失败；未保存会话凭据，未绕过平台限制 | 不推断链接永久失效；不把客户端探测失败说成模型资源不存在 |
| 权重使用范围未独立确认 | 代码Apache-2.0，官方研究权重入口；无文件内条款 | 不宣称无限再分发/商业使用权，资产门禁未完全通过 |
| 外部checkpoint序列化风险 | 没有加载任何文件 | 将来须官方来源+完整性核验后无凭据、无网络隔离加载，优先受限反序列化；不能随意回退任意pickle |
| 旧框架/Ada兼容性 | 本轮没有部署或算子测试 | Dependency/Operator均NotRun，不是Failed或Passed |
| Head匹配/原规格显存 | 无state_dict、无前向 | ModelLoad/Forward/Resource均NotRun；不以随机网络或降配替代 |
| CARLA坐标/yaw/颜色/类别 | 仅继承M8-0历史审查，条件工作包未启动 | 不复用旧审查冒充本轮闭合单测通过 |
| 感知质量和车辆安全 | 无CARLA域推理，无车辆控制 | QualityNotValidated、原安全门禁不变 |

本轮没有缺失的“成功 GPU 曲线”：这项实验没有发生。原系统环境保留了现有 Torch2.8.0，但没有拿它与旧 MMCV 临时混装，也没有使用它对外部权重进行未隔离读取。

如果将来重新提出资产恢复任务，应首先有可追溯官方完整文件或可重复有效的合法下载路径、文件使用范围和完整性材料，再独立决定是否重开门禁。用户若自行从官方入口取得文件，也仍需检查官方来源链、SHA、检测Head和关键Tensor，不能按文件名接受。当前不要求用户提供凭据，不自动重试、改框架、训练、扩展 Adapter 或接控制。

即使未来 P0 成功，最多标为 `FeasibilityPassed_QualityNotValidated`；六摄3D定位、独立风险校准、Occupancy、共享GPU实时性和RGB驾驶安全仍需各自证据。
