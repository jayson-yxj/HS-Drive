# M8-I1a 根因证据边界

**旧启动地图错误的根因仍为 Unresolved。** 已确认的是异常先于身份落盘、业务失败未转成非零进程退出码。这两项由旧源码和真实失败记录直接支持；新只读诊断版本完成离线修复。不能把可观测性缺口的修复称为地图启动问题已解决。

| 假设 | 已有证据 | 缺少什么 |
|---|---|---|
| 地图 argv 未被生效或被默认配置覆盖 | 旧 argv 有 Town02；包装脚本插入 CarlaUE4 首参；默认配置为 Town10HD_Opt | 实际加载 Map/日志与解析过程。默认值不等于真实运行值 |
| CWD 导致路径或配置解析不同 | 老通用脚本 cd 到安装根；M8-I1 Popen 无 cwd 参数 | 旧 /proc/cwd 已不存在；不能用当前 shell CWD 补写过去事实 |
| RPC 可访问但地图尚未稳定 | 旧就绪检查只读版本 RPC；无地图时间序列 | 同一进程内有界身份观测。不能靠扩大时效或重复启动证明 |
| Town02 包损坏或错误 XODR | 包中 Town02 与既有冻结资源 SHA 相同，本地 XODR 与期望一致 | 实际世界 XODR 尚未读取；本地完整性排除不了加载到其他地图 |

没有读取到新的真实地图、Episode、Frame 或 XODR。本轮不进行网络推断或把公开默认行为替代服务器证据。

拟议诊断保留原完整 argv、安装与资源，不修改地图配置，也不切换工作目录到安装根。显式设置当前仓库 CWD 并保存 /proc 证据；因旧 CWD 缺失，只能与旧继承机制作源码层对照，不能宣称严格历史单变量因果实验。新增被动确认窗口属于诊断变量。地图一旦不符，留证后停止，不等到偶然匹配、不 reload。

即使下一次成功，它只能说明该次配置具有可确认的启动身份；不能单凭一次成功倒推出上次根因。即使下一次仍失败，也只能依据新 Map/日志细化假设，不自动授权第二次实验。
