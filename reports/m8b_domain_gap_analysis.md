# M8-B 域偏移与失败诊断

这是实际RTX4090冻结权重推理+独立离线GT评价，不是新CARLA闭环或训练结果。依据固定协议、192帧/38位置组；源、权重、输入、全部输出SHA见release_manifest、selection_freeze及各JSON provenance。

**结论：输入与坐标合同闭合，零样本质量仍不合格；不能从此次失败推导PETR经过域适配后的能力上限。**

固定score>=0.1、同粗类中心XY<=2m且|Z|<=2m一对一匹配：155记录可见目标，45 TP、110 FN、11,090预测、11,045未匹配。Recall29.03%，相对不完整记录标注的Precision0.406%。这里的FP是annotation-unmatched，不是确认物理误检。全部57,600 topK保留，分数中位0.0521、P95 0.1918、最大0.9519；没有通过高阈值把结果删光。

Vehicle29/105、Person9/30、Cone7/20；0–10m为23/25，10–20m为21/47，20–40m为1/83。距离与类别/布局/位置并未控制为单变量，近场高Recall不能代表安全通过；自然匹配门限2m也对近场小物体相对宽松。>=40m无支持。front_right仅12、rear_right仅4目标；不能宣称六方向泛化可靠。只有1帧含两个已记录可见Actor，多目标遮挡能力证据不足。

条件投影关联独立于3D中心门限。92个score>=0.1关联，XY mean7.39m、median6.22m、P95 18.57m、max30.32m、>5m为56.52%；光学深度绝对误差均值6.12m，光学横向3.44m，径向7.32m。该关联是跨可见视角投影矩形最大IoU的一对一代理，可能关联错误；不能把92个全部声称为确认身份的检测。它揭示不能用自然2m子集P95=1.85m掩盖尾部风险。两套分母与关联局限均保留。

实例可见性与GT仅供Evaluator。265个Actor-view中48部分裁剪，原938,041支持像素保留804,234（损失14.26%）；0视角/0目标完全丢失。本样本不能将110个漏检简单归因为“整目标裁掉”。上下文减少、源640×384放大到1408×512、整数resize舍入、分辨率/FOV与nuScenes差异，仍可能影响特征与几何；本轮未做裁剪参数对照，因而未建立因果。

相机标定逆投影最大误差3.55e-14m；非方形旧box与HS角点误差约微米。真实参考upright近似角点误差均值0.0103m、P95 0.0569m、最大0.316m，远小于大多数米级中心误差，但它不是无影响的精确Mesh。位置嵌入接收到HS ego pseudo-LiDAR坐标，数学正确不保证符合预训练nuScenes LiDAR原点高度、相机安装和统计参考分布；本轮未更改参考系寻找好成绩，不能归因已解决。Yaw对称轴与有向Yaw均报告；Cone无明确朝向任务意义，汇总Yaw仅几何诊断，不能当驾驶意图预测。

代表例s107（历史Calibration；只用于展示）score0.759，投影关联XY误差8.23m，真实距离16.37m，upright IoU=0。六摄图像上框重叠并不能证明3D距离正确。对应 `m8b_figures/s107_six_camera_crop.png` 与 `s107_bev.png`。预测还大量落到道路设施：12,938个原始barrier候选没有对应完整标注类，不能用现有标注验证物理真假。Person原始11,204候选也不能凭类别计数当真实行人。未匹配背景需另设完整标签审计；不得把Unknown解释Free。

独立Calibration只有24目标，raw topK最多18投影关联，已达不到预声明20匹配支持；score0.1为14关联、P95 21.18m、>5m71.43%，自然Recall16.67%。提高到0.5只剩5关联、覆盖20.83%、>5m40%。固定网格没有合格阈值；阈值逐次重关联会换对象，因此曲线不是固定集合上的安全校准证明。Score与位置错误有部分负相关（Calibration Spearman约-0.482），不足以控制尾部。没有新独立盲测，所有统计最多PilotOnly。

与冻结Geometry Prior/Direct/Plane配对时，使用同GT Actor-view交集并保留并集和缺失。Val两种子Geometry Prior交集P95约2.85/3.12m，PETR对应约15.85m；旧Sealed对应约11.77/5.74m，PETR约12.03/11.07m。没有稳定PETR优势。候选机制、类别能力、关联代理和支持子集不同，不能把此表当严格架构因果消融；历史基线失败门禁仍保持。

时延也有域输入处理成本：GPU Forward P50 52.96ms/P95 53.51ms，真实完整E2E P50 330.44/P95 337.94/Max441.62ms，首帧718.69ms。主要CPU成本为resize/crop123ms、normalize/pad50ms、读取48ms和组装37ms。单帧allocator峰值1.03GiB/reserved1.25GiB满足24GB离线资源，但现有串行通路约3.03Hz，不满足5Hz/20Hz；没有改变正式时效预算。

下一步只建议独立有限诊断提案：先审查预训练参考分布（原点/高度/FOV/类别尺寸）与CARLA几何，在Train开发合同、Val诊断，补足右侧/远距/遮挡/完整背景标注，预留新最终位置。诊断后才能另行申请一次预算固定的域适配研究，并与冻结原checkpoint比较。当前不直接批准训练、不增加自定义Head、不以外部公开成绩替代CARLA结果；默认视觉、Planner、Safety、Controller和Physics保持不变。
