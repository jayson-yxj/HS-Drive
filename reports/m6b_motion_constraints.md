# M6-B 运动约束补充审查

来源：**实际CARLA日志的离线统计，Privileged**。源码与日志引用见 `m6b_motion_envelope.json`、`m6b_oracle_maneuver_results.json`，固定配置见 `configs/m6b/protocol.json`。

四次正式合法绕行的切向横向误差P95约0.113–0.118m，最大约0.128m；请求方向盘归一化值峰值约0.087，候选最大曲率约0.0317/m。规划采样内部Jerk约2.5m/s³、加速度上限1.5m/s²，没有因此认证实际车辆约束通过。

**真实速度也未完全遵循2.5m/s巡航上限**：道路126两次峰值2.922/2.935m/s，道路170为2.648/2.667m/s。规划器使用测得速度构建可减速轨迹，不能把规划巡航值解释成瞬时实际速度硬上限。该跟踪超调、真实Jerk和制动间距都是保持绕行整体Partial的原因。

C正式停车的HOLD段最大记录位移约0.00075m；这说明本批进入HOLD后未明显滑移，**不解决进入HOLD前越过目标**。原始前后速度、反向ticks、低速持续时间已保留，未研究倒挡泊车。

最坏真实减速度附近有些命令已切回normal，但前序硬制动响应仍在继续。`normal_braking_vs_safety`是时间窗口分组，不能用于证明对应物理峰值仅由当前命令产生；同时保留applied gear/brake和前序请求。需要受控系统辨识才能分离传动/接触/制动释放的因果贡献。

Runtime A虽然不启动Planner Worker或闭环Controller，但仍保留状态快照、传感器、地图/包络守卫与记录，以共同仪器框架测量。它不是完全无客户端负担的裸server基准，也没有行驶物理负载；不能据A/B差分精确归因Oracle成本。专门短测无结束deadline miss并不覆盖全部69次运行的15次miss和178.08ms长尾。
