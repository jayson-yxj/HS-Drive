# M6-D 决策：观测合同通过不能替代低速执行资格

**总体Partial / CandidateNoGo。** 保留默认Controller、原Physics、原Planner/Safety、视觉Shadow和历史全部质量状态。M5维持ResearchCompleted / CandidateNoGo / SafetyNotValidated。

## A：有符号运动合同

SignedMotionState的坐标、符号、沿路线投影、时间戳和非负OracleState兼容性，在真实CARLA Snapshot数据、SDK交叉计算及合成测试中通过有限接口验证；目标分离schema可继续研究。

但完整“检测回滑并进入保护”的门禁**No-go**：暖态p27释放时出现−0.081m/s间歇负速，位置也实际向后偏移约11.7mm，证明不是仅gear推断。每个负速片段被中间小正速打断，预声明持续.1s判据没有触发。不能将这些实际运动全部称为近零噪声，更不能通过测量schema的Go关闭保护门禁。未来若研究位移证据/滞回，需要新的预声明方案；本轮不改阈值或追加搜索。

## B：保持与重新起步

32组保持协议都能在原Physics下静止保持，最大观测漂移约0.246mm，支持有限静止保持Go，不包含到达指定Goal的能力。

完整正常保持/释放/重启**No-go**。固定前进1挡+handbrake诊断8/8能够在2s内起步，但释放原始Jerk约59.6–69.0m/s³；自动挡冷启动约3.6s，暖态虽快但部分道路出现实际回滑，Jerk约78.8–87.8。油门.10未起步不能用“低Jerk”认证可执行控制。普通.01制动真实减速度约11.95–24.70m/s²。状态机名称不能消除这些实际执行限制。

## C：正常停车执行

F1前置门禁失败，**NotRun**。开发9m的C和F0各2/4终点通过，冻结D2为0/4；正常舒适完整停车均0/4。F0本轮短路线没有触发回滑保护，不是其保护有效性的正证据。暖态两次保护探针提供反例。禁止升级候选或继续同策略参数扩展。

原四类故障保护在约1.51–1.60m/s实际注入时C/F0各4/4停止；不认证正常停车和3m间距。完整阻塞、绕行、前车恢复、25m、新道路封存矩阵因前置门禁未过而NotRun，历史能力不会自动继承给F0。初始静止故障保留，不计入行驶成功分子。

严格20Hz继续Partial：全28次开发闭环最大间隔350.13ms，不能排除静止故障这条长尾来宣称通过。无过期计划正常控制与严格实时性是两个不同事实。

## 是否申请独立Physics研究

有足够重复证据支持**提出限定范围、独立版本的Physics/执行接口辨识申请**，本轮没有执行。建议申请的目的为区分原Tesla传动初始化、轮胎/驻车接触状态、油门死区与小Brake强响应的作用；若获准，每次只改变一个明确参数族，保存新SHA，并保留原Physics配对。不要先许诺舒适性可通过，不将新Physics结果混为原控制器改善。

这些结果只支持`NoGo_CurrentPhysics_CurrentActuationPolicy`，不证明所有潜在控制方法均不可能。下一阶段的可选研究边界是有符号状态/位移保护合同和独立Physics可行性；不批准倒车泊车、复杂交通、视觉控制或正式Occupancy训练。
