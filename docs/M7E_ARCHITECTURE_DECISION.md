# M7-E 架构决策

**只保留离线研究基线，在线Planner Shadow与在线控制不批准。** 本阶段不因候选质量改善而关闭时效、执行、视觉、Occupancy或运行时门禁。

唯一F候选完成了实际初始XY、航向、前向速度的一致连接。开发和新采集不同道路的有限序列均有继续行驶增益，说明M7D的起点投影问题确有可修复部分。但不能把所有拒绝归因于初始状态：负实测速度、道路guide约束、动态停车余量和未知Actor走廊仍存在；旧最终road30没有新增继续行驶。新横穿目标维持Unknown，没有扩大运动假设族。

F使用单个五次Hermite几何连接与原速度时间律。初始加速度/Yaw Rate并非已观测，零计划初始加速度和曲率是显式假设。全车身、六秒、曲率、加速度/Jerk、3m停止余量及时间有效期不变。不能推断实际控制器可跟踪，也不能证明跨候选之间实际Jerk舒适。

静态区域缓存保持输出等价，但只移除了很小的一部分工作。新连接的密集guide和完整审核增加计算负担；不能为了200ms删安全查询、粗化车辆包络或放松时间戳。本轮不进行第二次缓存/采样/并行性能重构。

**停止当前M7实现的自动扩展，不自动启动M7-F。** 下一步应先在项目层明确计算架构和研究优先级：将保留的质量改进作为离线参考，另行评估是否需要有预算上界的轨迹表示、预计算道路接口与诊断输出分层。任何新计算结构须提供独立的几何/时间安全等价依据，不能在本轮顺手替换实现。

本轮门禁独立：接口/初始状态研究、独立有限参考覆盖、历史安全约束、完整结果时效、车辆执行分别报告。即使已有有限未来零冲突，也不能当成实际驾驶或完整动态安全。
