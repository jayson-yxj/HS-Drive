# M7-D 架构决策

本轮保留 `Partial / OfflineOnly / ControlNotAuthorized`。本轮没有把任何RGB、Occupancy、执行动力学或Runtime门禁改为Passed。

1. **继续保留真实时序离线基准。** 已有当前输入/未来参考分离、来源/时间合同、全部候选评估、逐时刻拒绝解释和独立原始轨迹。它比中心线合成快照更容易揭示真实状态适配问题。历史68份完整trace仅说明字段支持，未全部做质量认证；本轮选两段真实18秒窗口作回归。
2. **慢行不升级为可执行策略。** 冻结慢行的首点来自路线投影，不能保证等于实际Actor状态。真实横向/航向偏差下初始状态和曲率检查大量拒绝；修复需要独立研究初始条件一致的轨迹连接，不允许本轮根据最终结果修改候选族。没有证书时保留拒绝。
3. **多假设与真实未来安全分开。** 少量已接受候选在已记录未来无冲突，并不能覆盖脚本中超出声明加速度范围的全部物理行为。横穿目标没有明确运动走廊仍Unknown；单一实测未来安全不能反向证明拒绝错误。目标没有对反事实Ego响应，实际闭环未知。
4. **停止本轮性能重构。** 只实现同snapshot多边形复用；历史输出与真实序列配对逐项检查。冷缓存与真实移动序列均独立计时；不再增加缓存类型、缩短六秒或删假设以跨过200ms。
5. **在线Planner Shadow尚不批准。** 可以提出下一轮更窄的离线研究：实际初始状态轨迹连续性、受支持Actor运动域与路口合法意图、有限预算调度和过期结果拒绝。若要在线Shadow，需要另行规定非阻塞采集、计算队列上界、结果时效、唯一tick owner和故障回放；不得连接正常控制。

默认M7C行为和历史实现不改。本轮采集脚本的碰撞记录不删除，也不当成新Planner的车辆碰撞；车辆没有执行新Planner输出。最终道路结果不用于调参后重称盲测。下一轮应使用新的最终片区。
