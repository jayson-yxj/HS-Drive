# M5-L 架构决策与预声明

基线 `0175f21`，独立研究分支。旧默认Encoder、48LID、HeightSplat、BEV网格、Runtime与Physics不改。旧M5-K Test只作回归。

1. P4训练要求Train/Val各4位置、100条严格20–35m Actor射线且至少两类各20条。原可靠Mask不放宽，P8全64相位仅诊断。现有P4行人各9条，因此暂停P4 Depth训练，不反复补相同布局。
2. Vehicle-only是本轮新范围，不能追溯改变M5-K两类别门禁。零残差B/C同容量、同初始化、同采样顺序、同Loss，两个种子各600步；只更新残差，保留M4近场CE与新旧近场KL。50%车辆支持camera、50%均匀camera；其他前景类别不参与优化，但均单列评估。Val仅选0/200/400/600，禁止追加步数掩盖失败。
3. 真P4由Mobile layer3实际S4浅层24通道与已训练P8语义64通道在指定UV采样融合，卷积中心0+stride*i；Depth历史名义中心4+8i单列。P8概率插值不是高分辨率Depth模型。P4仅工程探针，不用未训练输出报告质量。
4. 2.5D基线采用固定z=-0.25m平路假设、RGB q≥0.9连通域底部中值UV、K/T射线交平面。图像边界、宽合并候选、近地平线与±0.1m平面/±1像素敏感度>3m时abstain。二值前景无法证明接地/底部可见，所有几何输出均为条件假设，不得作为可信3D目标。GT仅用于匹配及坡度、接触可见性分层。AABB中心和可见底部端点分别评价；都不是精确轮胎接地点。
5. Adaptive固定原公式。新增同RGB前景区域包围矩形内均匀对照，逐帧同预算。新Oracle端点格与既有概率质量跨阈值是可重叠事件，禁止相加当因果比例。Val锁定同FPR/同Recall阈值，测试原样运输。
6. 新封存位置仅在完成312帧研究并冻结方法后采集；包括平路、坡道、方向变化、遮挡及小目标。名义摆放不等于有效监督。坡道上Actor相对Ego平面摆放可能悬浮/穿地，实际底部与场景可靠性必须单列，不能宣称物理接地真值。
7. 在线Shadow仅2Hz独立进程，sole harness Tick Owner，最新完整六摄包，原sim timestamp不改，250ms墙钟过期丢弃。基线/并发/恢复各240计量ticks；P95恶化超过max(1.5倍,基线+20ms)或单tick>1s停止。静态传感器工程实验不代表驾驶资源争用或控制安全。

数值门禁和Loss见`configs/m5l_protocol.json`。三个架构决定分别报告，不以训练收敛代替质量认证。
